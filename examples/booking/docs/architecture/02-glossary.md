# 予約 CLI サンプルの用語集

> **TL;DR**: 予約・枠・テナントの意味と、対応するコード上の識別子を 1:1 で固定する。

## 1. 用語

| 用語 | 英語識別子 | 定義 | 混同しやすい語 |
|---|---|---|---|
| 予約 | Reservation | 1 人の利用者が 1 つの予約枠を押さえた記録。状態を持つ | 予約枠 (枠は入れ物、予約は中身) |
| 予約枠 | TimeSlot | 同時に受け入れられる人数 (定員) を持つ時間帯 | 予約 / 在庫 (在庫という語は使わない) |
| 定員 | capacity | 予約枠が受け入れられる最大件数。1 以上の整数 | 残数 (残数は導出値) |
| 残数 | remaining | 定員から確定済み件数を引いた値。保存せず毎回導出する | 定員 |
| 確定 | confirm | draft の予約を枠の消費とともに確定させる操作 | 作成 (作成は枠を消費しない) |
| テナント | TenantId | データの分離単位。全操作がこの値を必要とする | 利用者 (利用者は本サンプルでは登場しない) |
| 集約 | aggregate | 同時に守るべき不変条件の単位。保存も集約ごと | モジュール |
| ポート | Port | ドメインが要求する外部との接点。実体は adapter が持つ | adapter (実装側) |

## 2. 会話で混同しやすい語の使い分け

- **作成と確定を分ける**: 「予約した」は作成 (draft) と確定 (confirmed) のどちらも指しうる。本サンプルでは必ず作成・確定と言い分ける。
- **在庫と言わない**: 定員と残数で表す。在庫という語は物販の語彙と混ざるため使わない。
- **削除と言わない**: 予約は削除せずキャンセルする。状態は cancelled で残る。
