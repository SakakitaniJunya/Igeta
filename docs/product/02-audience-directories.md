# 要件定義書 — 読み手別ディレクトリ (docs/ の物理分割)

> **TL;DR**: docs/ を開いた人が、読み手の境界をフォルダ構造から即座に読み取れない、を解く。
> docs/ 直下を読み手別ディレクトリに物理分割し、kind→読み手→ディレクトリの対応を正本 1 つに置き、配置違反を検査で落とす。
> - v0.4.0 の索引表示 (`_(読み手: X)_`) は索引を経由しないと見えない。文書を直接開く・docs/ 直下を眺める、では読み手が分からない
> - 文書発見はパス非依存 (frontmatter の kind / arc42 / depends_on) なので、移動で壊れるのは相対パス参照だけ
> - やらない: `audience` フィールド新設 / 新しい kind / 読み手別の生成物語 (前版のスコープ外を継続)
